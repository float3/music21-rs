About

The twenty scale types music21 defines as classes, realized from any tonic over one octave with the spelling music21's interval networks give them. Deriving tries every type from every tonic music21 tries and ranks them by how many of the given pitches each holds.

For scales in other tunings, the Scala archive and regular temperaments, see the Tuning Explorer.
